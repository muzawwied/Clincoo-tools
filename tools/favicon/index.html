Cara membuat favicon

  1. 1
    Pilih sumber ikon

    Mulai dari huruf atau inisial, emoji, atau gambar logomu sendiri.

  2. 2
    Atur tampilannya

    Pilih template, warna, bentuk, dan huruf. Pratinjau langsung berubah.

  3. 3
    Cek pratinjau

    Lihat ikonmu di tab browser terang dan gelap, plus di layar utama HP.

  4. 4
    Unduh paketnya

    Satu file .zip berisi ICO, PNG, SVG, dan manifest, siap dipasang.

Pasang di website

  1. 1
    Unggah file

    Taruh semua file dari paket .zip di folder utama (root) websitemu.

  2. 2
    Tempel kode

    Salin kode di samping ke dalam <head> setiap halaman.

  3. 3
    Muat ulang paksa

    Tekan Ctrl atau Cmd + Shift + R. Kalau belum berubah, buka di jendela privat.

Pertanyaan yang sering muncul

    

      
Apakah Clincoo Favicon gratis?
Ya. Gratis, tanpa daftar, tanpa iklan, dan tanpa watermark di hasil unduhan.

      
File apa saja yang ada di paket .zip?
favicon.ico (16, 32, dan 48 px), PNG 16 dan 32 px, apple-touch-icon 180 px, ikon Android 192 dan 512 px, site.webmanifest, dan file berisi kode siap tempel. Untuk jenis Emoji dan Gambar, favicon.svg ikut disertakan.

      
Bagaimana cara memasangnya di website?
Unggah semua file ke folder utama (root) websitemu, lalu tempel kode yang tampil di bawah pratinjau ke dalam <head> setiap halaman. Banyak platform seperti WordPress, Shopify, dan Wix juga punya kolom ikon situs, tempat kamu bisa mengunggah PNG 512 px.

      
Kenapa favicon saya tidak berubah setelah dipasang?
Browser menyimpan favicon di cache cukup lama. Coba muat ulang paksa (Ctrl atau Cmd + Shift + R), tutup tab lalu buka lagi, atau buka websitemu di jendela privat.

      
Apakah gambar saya diunggah ke server?
Tidak. Semuanya diproses langsung di browser kamu, jadi teks dan gambar yang kamu pakai tidak perlu dikirim ke mana-mana.

      
Gambar seperti apa yang cocok jadi favicon?
Gambar persegi, minimal 512 x 512 px, dengan bentuk sederhana dan kontras tinggi. Detail halus dan tulisan kecil akan hilang saat dikecilkan ke 16 px.
